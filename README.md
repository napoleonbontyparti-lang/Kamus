# KataCil

*kata* — «слово», *-cil* — от *kancil* и *kecil* («маленький»).

Офлайн-словарь индонезийского языка для Android и iPhone по мотивам Pleco. В основе — «Большой индонезийско-русский словарь» Р. Н. Коригодского и соавторов. Если слова в словаре нет, приложение отправляет в KBBI. Слова можно сохранять в карточки и тренировать в шести режимах.

## Что умеет

**Словарь (работает без интернета)**
- 34 355 гнёзд и около 55 тысяч словоформ из оцифрованного словаря.
- Разбор аффиксов при поиске. Можно ввести *dipertanggungjawabkan*, *rumahnya*, *ketidakadilan*, *buku-buku*, и приложение покажет разбор (например, «ke- + tidak- + ADIL + -an») и найдёт гнездо. Понимает di-, me(N)-, pe(N)-, ber-, ter-, per-, ke-, se-, -kan, -i, -an, -nya, -ku, -mu, -lah, -kah, -pun, удвоение и назализацию (memukul → pukul, menyapu → sapu).
- Если ввести корень (например, *tanda*), под ним сразу видны все производные: из его гнезда и из других статей, включая составные (*menandatangani*, *penandatanganan*).
- Цветные аффиксы, как тоны в Pleco: приставки, корень, суффиксы и частицы — своими цветами (вкладка «Ещё», по умолчанию выключено).
- Подсказки по мере набора, поиск по русскому переводу (обратный поиск), история поиска.
- Статья оформлена как в бумажном словаре: значения пронумерованы, «~» раскрывается в слово, пометы выделены курсивом, фразеология (◊) вынесена отдельным блоком, ссылки «см. …» кликабельны. Указан номер страницы в печатном издании, соседние статьи можно листать.
- Озвучка индонезийским голосом телефона.
- Исправление ошибок распознавания прямо в статье (карандаш). Правки хранятся отдельно и переживают обновление базы.

**Календарь.** Как в VoCat: по дням видно, какие слова добавлены (с временем) и какие тренировки пройдены (режим, колода, верно/ошибки). Долгое нажатие на день — меню: отметить все слова дня выученными / невыученными, снять метки, потренировать слова дня.

**Метки-копытца.** У каждой карточки копытце: бирюзовое — выучено, янтарное — не выучено. В колоде есть фильтр по меткам.

**Страница «Мой».** Резервная копия на Google Диске (через меню «Поделиться» → «Диск») и восстановление из неё, тема (светлая по умолчанию / тёмная / как в системе), цветные аффиксы, исправленные статьи, экспорт в Anki.

**Поиск по фото.** Кнопка камеры в строке поиска: сфотографировать текст или выбрать фото, выделить нужный фрагмент — приложение распознает текст (Google ML Kit, без интернета), подчеркнёт найденные в словаре слова и покажет их перевод.

**Настройки.** Профиль (аватар из камеры или галереи, никнейм, уникальный код, ключ восстановления), друзья и рейтинг за неделю, ежедневная цель (сколько слов в день), вибрация (по умолчанию выключена), тема, цветные аффиксы, резервная копия.

**Виджет Android.** Канчиль, синий огонёк и число дней подряд (и прогресс цели). Добавляется долгим нажатием на главном экране → «Виджеты» → KataCil.

**Сервер (Supabase).** Друзья, рейтинг, облачная копия и восстановление аккаунта по коду и ключу. Схема — `supabase/schema.sql` (выполнить один раз в SQL Editor), адрес и публичный ключ — в `app.json → expo.extra.supabase`.

**Награды и Секти.** Достижения с уровнями (Api Biru, Si Rajin, Pengumpul Kata, Kancil Cerdik, Tanpa Cela, Hafal Luar Kepala, Jago Imbuhan, Latihan Terus, Penjelajah Kamus, Mata Elang, Teman Sejati). За каждый уровень — Секти, внутренняя валюта в виде звёздочек. Статистика занятий.

**Автосохранение в облако KataCil** при закрытии приложения (не чаще раза в 10 минут) и раз в сутки при запуске.

**KBBI.** Кнопка внизу результатов поиска и «KBBI» в заголовке статьи открывают официальный KBBI daring внутри приложения. Для этого нужен интернет.

**Карточки**
- Закладка у любого слова в статье создаёт карточку: перевод и корень подставляются сами, их можно поправить. Можно создать сколько угодно колод и добавлять карточки вручную.
- Режимы тренировки:
  1. **Повторение** — интервальное повторение по алгоритму FSRS (как в современном Anki) с оценками «Снова / Трудно / Хорошо / Легко».
  2. **ID → RU** — выбрать перевод из четырёх вариантов.
  3. **RU → ID** — выбрать индонезийское слово.
  4. **Написание** — вписать слово по переводу.
  5. **Аффиксы** — дан корень и значение, нужно образовать форму (adu + «жаловаться» → *mengadukan*).
  6. **Верно / неверно** — на скорость.
- Экспорт колод в формате Anki (TSV).

## Как запустить на телефоне

Понадобится компьютер (Windows или Mac) с установленным [Node.js](https://nodejs.org) версии 20 или новее.

### Вариант 1. Быстро посмотреть: Expo Go (Android и iPhone)

1. Установите на телефон приложение **Expo Go** из Google Play или App Store.
2. На компьютере распакуйте архив, откройте терминал в папке `kamus` и выполните:
   ```
   npm install
   npx expo start
   ```
3. На экране появится QR-код. На Android отсканируйте его в Expo Go, на iPhone — обычной камерой. Телефон и компьютер должны быть в одной сети Wi-Fi. Если не подключается, запустите `npx expo start --tunnel`.

При первом запуске словарь распаковывается несколько секунд. В этом режиме приложение работает, пока на компьютере запущен `expo start`.

### Вариант 2. Настоящее приложение для Android (APK)

Сборка идёт в облаке Expo, Android Studio не нужна:
```
npm install -g eas-cli
eas login            # бесплатный аккаунт на expo.dev
eas build -p android --profile preview
```
Через 10–20 минут EAS пришлёт ссылку на APK. Скачайте его на телефон и установите (Android попросит разрешить установку из этого источника).

### Вариант 2б. APK через GitHub (без Expo-аккаунта и Android Studio)

1. Создайте на github.com новый репозиторий (можно приватный) и загрузите в него содержимое папки `kamus` вместе со скрытой папкой `.github`. Проще всего через GitHub Desktop или командами `git init`, `git add .`, `git commit -m init`, `git push`.
2. Откройте вкладку **Actions**, выберите **Build Android APK** и нажмите **Run workflow**. Сборка запускается и сама при каждом push в `main`.
3. Через 15–25 минут откройте завершённый запуск. Внизу, в блоке **Artifacts**, будет **katacil-apk**: скачайте его, распакуйте и перекиньте `app-release.apk` на телефон.

APK подписан отладочным ключом. Для личного использования этого достаточно, а для Google Play понадобится собственный ключ (его создаёт `eas build`).

### Вариант 3. iPhone

Чтобы приложение жило на iPhone постоянно, нужен аккаунт Apple Developer (99 $ в год):
```
eas build -p ios --profile preview     # установка на свои устройства (ad hoc)
eas build -p ios --profile production && eas submit -p ios   # TestFlight / App Store
```
Без этого аккаунта на iPhone остаётся вариант 1 (Expo Go).

## Устройство проекта

```
src/app/                 экраны (Expo Router)
  (tabs)/index.tsx       поиск
  (tabs)/decks.tsx       колоды
  (tabs)/more.tsx        о словаре, экспорт, исправленные статьи
  entry/[id].tsx         словарная статья
  kbbi/[word].tsx        KBBI во встроенном браузере
  deck/[id].tsx          колода и выбор режима
  study/[deckId].tsx     все режимы тренировки
  card/[id].tsx          создание и правка карточки
  edit-entry/[id].tsx    исправление статьи словаря
src/lib/stemmer.ts       разбор индонезийских аффиксов
src/lib/dict.ts          поиск по словарю
src/lib/userdb.ts        колоды, карточки, FSRS, история, правки
src/components/Definition.tsx   оформление статьи
assets/dictionary-v2.db  база словаря (SQLite)
tools/                   конвейер «PDF → база»
tests/                   тесты стеммера и поиска
```

Пользовательские данные (карточки, история, правки) хранятся в отдельной базе `user.db` и не стираются при обновлении словаря.

## Как пересобрать базу словаря из PDF

Нужны Python 3 и `pdftotext` (пакет poppler-utils):
```
pdftotext -bbox-layout Korigodsky.pdf build/bbox.html
python3 tools/lines.py build/bbox.html build/lines.json        # строки по колонкам
python3 tools/parse_dict.py build/lines.json build/entries.json # статьи
python3 tools/build_db.py build/entries.json assets/dictionary-v3.db
```
Новую версию базы называйте новым именем (`-v3`) и меняйте имя в `src/app/_layout.tsx`: тогда при обновлении приложения база скопируется заново.

Что исправляет разбор: латинские буквы, распознанные кириллицей (Ьегасага → beracara), «I» вместо «l» (pukuI → pukul), «оо/со» вместо «~», «Q/П/□» вместо «◊», переносы и колонки, склеенные ABBYY. Ложные заглавные слова отсекаются проверкой алфавитного порядка, производные — проверкой «приставка + корень».

**Известные ограничения OCR.** Часть статей распознана с ошибками, например заглавное слово *tulis* потерялось, а *tangan* попало в статью *tang*. Их можно исправить в приложении (карандаш в статье). Правки выгружаются в JSON на вкладке «Ещё», чтобы перенести их в следующую версию базы.
